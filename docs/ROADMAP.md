# Roadmap

| Phase | Focus | Deliverable | Status |
|---|---|---|---|
| 0 | Compatibility and research | Compatibility report, minimal spike, fake repo scaffold | ✅ code complete; manual TUI verification pending |
| 1 | Agent Command Center | Sidebar overview, hierarchy, activity, session navigation | ✅ code complete; manual verification pending |
| 2 | Events and Permissions | Bounded timeline, filters, permission visibility, RPC history | ✅ code complete; manual verification pending |
| 3 | Usage and Project Intelligence | Usage breakdown, cost provenance, Git status, test evidence, compact mode | ✅ code complete; manual verification pending |
| 4 | Harness Inspector | Evidence model, instruction/spec/criteria checks, quality dashboard | ✅ code complete; manual verification pending |
| 5 | Stabilization and Distribution | Compatibility checks, stability tests, packaging, docs, MIT license | ✅ code complete; publish blocked on owner approval |

Feature priorities:

- **P0 Required MVP** — Phase 0–1 core plus permission visibility, basic usage,
  empty/loading/unsupported states, bounded timeline, cleanup, tests, docs.
- **P1 Observability Expansion** — Phase 2–3 panels and breakdowns.
- **P2 Development Intelligence** — Phase 4 evidence and quality.
- **P3 Advanced** — cross-project, custom adapters, policies, historical analytics.

Do not implement all phases at once. Each phase requires explicit approval.
